The content inside this folder is a plain copy from the packs folder from Foundryborne/Daggerheart system: https://github.com/Foundryborne/daggerheart/tree/main/src/packs

Using .github/workflows/check-new-content.yml this content is kept up-to-date with the upstream Daggerheart system.

These plain files, after being copied, are translated to portuguese (only names and descriptions, keeping the rest of the content unchanged).

Then, using this module's code, the packs (compendiums) are translated at runtime.
