# Daggerheart - Tradução para Português Brasileiro

Módulo de tradução para Português Brasileiro (pt-BR) do sistema [Daggerheart](https://github.com/Foundryborne/daggerheart) para o FoundryVTT.

## Por que este módulo?

Outras traduções estavam incompletas em relação à versão mais recente do sistema e exigiam módulos extras. Esta é completa e **não depende de outros módulos**.

## Requisitos

- FoundryVTT v13 ou superior (verificado na v14.370)
- Sistema Daggerheart instalado

## Instalação

1. No FoundryVTT, vá em **Add-on Modules** → **Install Module**.
2. Cole o link do manifesto no campo **Manifest URL**:

   ```
   https://github.com/TaylorHo/fvtt-daggerheart-translations-pt-br/releases/latest/download/module.json
   ```

3. Clique em **Install**.

## Uso

1. Abra o seu mundo do Daggerheart.
2. Em **Game Settings** → **Manage Modules**, ative o módulo.

## Contribuindo

Encontrou um erro de tradução? Abra uma issue ou PR em [TaylorHo/fvtt-daggerheart-translations-pt-br](https://github.com/TaylorHo/fvtt-daggerheart-translations-pt-br). As traduções ficam em `lang/pt-BR.json`.
